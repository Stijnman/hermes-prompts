# Hermes Prompts

**Description**: A comprehensive library of AI prompts for Hermes and other AI assistants, enabling advanced conversational capabilities and task automation.

**Purpose**: Enable AI agents to leverage specialized prompts for various domains, including reasoning, coding, research, and creative tasks.

---

## 🎯 Quick Start

### For AI Agent Developers

1. **Browse the library** of prompts below
2. **Select** the prompt that matches your use case
3. **Customize** with user-specific details
4. **Execute** and monitor results
5. **Iterate** based on feedback

### For Users

Tell your AI agent:
- "Use the deep research prompt to analyze this topic"
- "Apply the coding best practices prompt for this script"
- "Use the reasoning chain prompt to solve this problem"
- "Give me the latest Hermes system prompt"
- "What prompts are available for creative writing?"

Your agent will select and apply the appropriate prompt.

Hermes Prompts is a curated collection of high-quality AI prompts designed for various use cases and domains. The library includes prompts for reasoning, coding, research, creative work, and specialized applications.

## 🎯 Key Features

### Reasoning Prompts
- **Chain of Thought**: Multi-step reasoning with intermediate reasoning
- **Deep Analysis**: In-depth analysis of complex topics
- **Problem Solving**: Structured problem-solving approaches
- **Decision Making**: Framework for making informed decisions

### Coding Prompts
- **Code Generation**: Write clean, efficient code
- **Code Review**: Analyze and improve existing code
- **Best Practices**: Follow coding standards and best practices
- **Debugging**: Identify and fix code issues
- **Documentation**: Generate comprehensive documentation

### Research Prompts
- **Deep Research**: Comprehensive research on any topic
- **Literature Review**: Survey existing literature and sources
- **Data Analysis**: Analyze and interpret data
- **Competitive Intelligence**: Research competitors and market trends

### Creative Prompts
- **Creative Writing**: Generate stories, poems, and creative content
- **Content Creation**: Create blog posts, articles, and marketing content
- **Brainstorming**: Generate ideas and solutions
- **Design**: Create design concepts and specifications

## 🔒 Security Overview

⚠️ **IMPORTANT**: These prompts may handle sensitive information and generate content that could be used in various contexts.

**Please read [SECURITY.md](./SECURITY.md) before using these prompts.**

### Key Security Principles

1. **Content Safety**: Ensure generated content is safe and appropriate
2. **Data Privacy**: Never include sensitive personal data in prompts
3. **Ethical Use**: Use prompts for ethical and legal purposes only
4. **Attribution**: Properly attribute sources and references
5. **Compliance**: Follow all applicable laws and regulations

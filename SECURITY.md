# Security Policy

## ⚠️ Critical Warnings

This library contains prompts that may be used to generate content, perform research, and automate tasks.

**All agents, users, and developers MUST read and understand this document before using these prompts.**

---

## Developer Responsibilities

You **MUST** ensure:

### 1. Ethical Use
Always ensure prompts are used for ethical and legal purposes:
- No malicious intent
- No harmful content generation
- No violation of laws or regulations
- No violation of platform terms of service

**Ethical use must be:**
- Lawful and compliant
- Respectful of others
- Non-discriminatory
- Non-exploitative

### 2. Content Safety
All generated content must be safe and appropriate:

**Never generate:**
- Hate speech or discriminatory content
- Violent or harmful content
- Illegal content
- Personal attacks or harassment
- Misinformation or disinformation
- Explicit or inappropriate content

**Always:**
- Review generated content before use
- Add content warnings when appropriate
- Respect content ratings and restrictions
- Allow user opt-out

### 3. Data Privacy
Never include sensitive personal data in prompts or outputs:

**NEVER include:**
- Personal identifiers (SSN, ID numbers)
- Financial information (credit cards, accounts)
- Medical information
- Private communications
- Authentication credentials

**ALWAYS:**
- Anonymize data
- Use placeholder values
- Respect privacy regulations
- Obtain consent for data use

### 4. Attribution
Properly attribute sources and references:
- Cite sources when using proprietary content
- Attribute generated content appropriately
- Respect copyright and intellectual property
- Follow fair use guidelines

---

## User Warnings

**Before using these prompts, be aware that:**

1. **Content Responsibility**: You are responsible for all content generated using these prompts.

2. **Accuracy**: AI-generated content may be inaccurate, incomplete, or biased. Always verify critical information.

3. **Bias**: AI models may have biases. Be aware of potential bias in generated content.

4. **Ethical Concerns**: Some uses of AI may have ethical implications. Consider these carefully.

5. **Legal Compliance**: Ensure your use complies with all applicable laws and regulations.

6. **Platform Policies**: Follow all platform terms of service and acceptable use policies.

## Compliance Considerations

### Legal Compliance
- Comply with all applicable laws and regulations
- Respect copyright and intellectual property rights
- Follow data protection regulations (GDPR, CCPA, etc.)
- Respect platform terms of service

### Ethical Guidelines
- Use AI responsibly and ethically
- Avoid harmful applications
- Respect human dignity and rights
- Promote fairness and equity
- Be transparent about AI use when appropriate

### Platform Policies
- Follow all AI platform terms of service
- Respect rate limits and usage restrictions
- Don't bypass platform protections
- Report violations appropriately

---

## Security Best Practices

### Prompt Security
- Review prompts for potential misuse
- Add appropriate warnings and disclaimers
- Validate user inputs to prompts
- Sanitize prompt outputs
- Implement content filtering when appropriate

### Data Security
- Never store sensitive data in prompts
- Use secure methods for data transmission
- Anonymize all personal data
- Respect data minimization principles

### Access Control
- Restrict access to sensitive prompts
- Implement appropriate authentication
- Log prompt usage for audit purposes
- Regularly review access controls

---

## Incident Response

### If You Discover a Security Issue

**DO NOT:**
- Open a public GitHub issue
- Discuss in public forums
- Wait to report

**DO:**
1. Email immediately: security@stijnman.com
2. Include:
   - Steps to reproduce the issue
   - Impact assessment
   - Suggested fix (if you have one)
3. Wait for acknowledgment
4. Give maintainers reasonable time to fix

### If Prompts Are Misused

1. **Document** the misuse
2. **Report** to appropriate authorities if illegal
3. **Review** and update prompts to prevent misuse
4. **Add** additional warnings and safeguards
